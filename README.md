# Ekstrem 1.0.0

> Turkish credit card statement analyzer — track spending, installments & payment deadlines.

## Overview
Ekstrem securely analyzes credit card statements from Turkish banks (via Gmail integration or manual PDF upload) to provide:
- 📊 Last 6 months spending analysis & categorization
- 📅 Installment tracking & timeline
- 🔔 Payment deadline notifications
- 💳 Multi-card consolidated dashboard
- 🔄 Recurring payment detection & price alerts

## Target Market
🇹🇷 Turkey only — supporting top 15-20 Turkish banks

## Tech Stack
- **Frontend**: React + Vite
- **Mobile**: Capacitor (iOS + Android)
- **Language**: Turkish UI
